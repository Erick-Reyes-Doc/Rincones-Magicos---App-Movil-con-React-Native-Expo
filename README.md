# 📍 Rincones Mágicos - App Móvil con React Native + Expo

**Rincones Mágicos** es una aplicación móvil creada con **React Native y Expo**, diseñada para explorar y descubrir los pueblos mágicos del sureste de México 🗺️✨

---

## 🧭 ¿Qué hace esta app?

- 📌 Muestra una lista de **Pueblos Mágicos** de Yucatán.
- 🗺️ Usa mapas interactivos (Mapbox o React Native Maps).
- 🖼️ Visualiza tarjetas con imágenes, descripciones y ubicación.
- 🔎 Permite ver detalles de cada lugar en un modal.
- 🧠 Navegación con `expo-router` y componentes dinámicos.
- 💾 Almacena datos localmente para modo offline.

---

## ⚙️ Tecnologías utilizadas

- 📱 React Native + Expo
- 🧭 expo-router
- 🗺️ Mapas (expo-maps / react-native-maps)
- 💾 AsyncStorage (para guardar datos locales)
- 📦 JavaScript (ES6+), Hooks (`useEffect`, `useState`)
- 🧭 Tailwind + Expo (opcional si se usa diseño con estilo)
